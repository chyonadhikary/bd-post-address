# বাংলাদেশের পোস্ট অফিসের ঠিকানা

Static GitHub Pages-compatible version of the Bangladesh post-office helper site.

Published site: https://chyonadhikary.github.io/bd-post-address/

The directory data and image assets are bundled in this repository so client-side search, label generation, fee calculation, and external tracking links work without the original Manus storage service.
